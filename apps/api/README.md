# apps/api - Backend NestJS (El Encanto Campestre)

Espacio reservado para la API REST del restaurante construida con NestJS y Prisma.

- **Responsable:** Alex Santacruz
- **Documentacion Swagger:** http://localhost:3000/api/docs
- **Prefijo global de rutas:** `/api/v1`

## Instrucciones para inicializar (Alex):

1. Inicializar el proyecto NestJS en esta carpeta.
2. Configurar el `Dockerfile` y `docker-compose.yml` para desarrollo local.
3. Conectar Prisma con Supabase usando los esquemas de `packages/shared`.

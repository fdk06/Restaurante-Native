# apps/mobile - App Móvil React Native (El Encanto Campestre)

Aplicación móvil bare de El Encanto Campestre desarrollada en React Native 0.87 con Nueva Arquitectura y motor Hermes.

- **Responsable:** Yeison Muñoz
- **Destinos de navegación:** Carta, Reservas, Noticias (botón central), Próximamente, Ajustes.
- **Tokens de diseño:** Vinculados desde `design/01_tokens/tokens.json`.
- **Internacionalización:** Textos externalizados con `i18next` en español (`es.json`).
